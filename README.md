# 📊 SQL (MySQL) Data Analysis Portfolio

Welcome to my **SQL (MySQL) Data Analysis Portfolio**.  
This repository contains a collection of hands-on SQL projects focused on **data cleaning, exploratory data analysis (EDA), aggregation, and analytical reporting** using real-world datasets.

Each project demonstrates practical SQL techniques commonly used by **Data Analysts, Business Intelligence professionals, and Analytics Engineers**.

---

## 🎯 Purpose of This Repository
The goal of this portfolio is to:
- Showcase strong **SQL querying and analytical thinking**
- Demonstrate **real-world exploratory data analysis workflows**
- Highlight proficiency with **aggregations, joins, window functions, and CTEs**
- Provide clear, well-documented, and reproducible SQL projects

## 📁 Projects Overview

### 📌 Project 1: Travel Planner Database
**Focus:** Database structure and query logic  
- Designed SQL queries to support travel planning use cases  
- Demonstrates filtering, joins, and aggregation logic  
- Emphasizes clean query structure and readability  

---

### 📌 Project 2: Layoffs Dataset Cleanup & Validation
**Focus:** Data quality and preparation  
- Removed duplicates and inconsistencies  
- Standardized date and text fields  
- Validated numerical and categorical data  
- Prepared the dataset for downstream analytics  

---

### 📌 Project 3: Retail Sales Analysis
**Focus:** Business performance analysis  
- Analyzed sales trends and revenue performance  
- Aggregated metrics by product, time, and category  
- Supported insight generation for business decision-making  

---

### 📌 Project 4: Global Layoffs Dataset (Exploratory Analysis)
**Focus:** Exploratory Data Analysis (EDA)  
- Identified trends in layoffs across companies, industries, and countries  
- Analyzed layoffs over time (yearly and monthly)  
- Used window functions (`DENSE_RANK`, `SUM() OVER`) for ranking and rolling totals  
- Highlighted peak layoff periods and most impacted organizations
